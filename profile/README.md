> StreamHome is currently a private project and is not yet publicly available.

StreamHome bridges the gap between premium VOD streaming experiences and the freedom of self-hosting.

Powered by a high-performance ASGI Python backend and a modern React 19 frontend, StreamHome transforms personal media libraries into a complete streaming platform with adaptive HLS playback, intelligent TMDB cataloging, personalized recommendations, source-agnostic media ingestion, automated recovery, and native Google Drive integration.

Your media remains entirely under your control—stored locally, synchronized with your own cloud storage, and presented through three distinct premium interface themes.

## 🌐 The StreamHome Ecosystem

StreamHome is built as an extensible ecosystem. The core server handles ingestion, processing, storage, cataloging, recommendations, and playback, while separate integrations can communicate with it through the MediaSender API.

### Core Platform

* **StreamHome**
  The main self-hosted VOD platform, including the server, web interface, setup wizard, adaptive player, recommendation engine, local and cloud storage systems, and MediaSender API.

### Browser Integrations

* **StreamHome Extension for Chrome**
  Browser integration for Chrome and Chromium-based browsers. Detects compatible media sources and sends them directly to a user-owned StreamHome server.

* **StreamHome Extension for Firefox**
  Browser integration for Mozilla Firefox, providing the same MediaSender workflow and direct StreamHome server integration.

## ✨ Platform Highlights

* Adaptive fMP4 HLS streaming
* Personalized recommendation engine
* Google Drive and Rclone integration
* Guided web-based setup wizard
* Automated TMDB metadata and artwork
* Source-agnostic MediaSender API
* Local and cloud database backups
* Portable metadata-based recovery
* Optional HEVC storage optimization
* Three distinct themes: Ember, Aurora, and Cinema
* Installable Progressive Web App
* GPLv3 open-source licensing
